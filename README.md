Java Calculator

A simple menu-driven Java calculator program that demonstrates the use of an interface and basic arithmetic operations.

Subtraction
Multiplication
Division

Menu-driven user interaction
Concepts Used
Java Interface

Methods

Basic arithmetic operations
Error handling
How It Works

The program defines a Calculator interface with methods for addition, subtraction, multiplication, and division. The myCalculator class implements these methods.

The user selects an operation from the menu and enters two numbers. The program performs the selected arithmetic operation and displays the result. The program continues until the user selects the Exit option.

How to Run
Make sure Java is installed on your computer.
Open a terminal in the project folder.
Compile the program:
javac CalculatorDemo.java
Run the program:
java CalculatorDemo
Menu
====== Calculator =======

1) Addition
2) Subtraction
3) Multiplication
4) Division
5) Exit

The program also checks for division by zero and displays an error message instead of performing the operation.
